## 自动化验收

`npm ci --ignore-scripts` 安装锁定版本，`npm test` 自动重建 `client.js` 后执行全部测试，61 项通过。`git diff --check` 通过。项目没有独立 lint/typecheck 脚本。

- 写入、文件 fsync、rename 失败：明确失败，不推进 revision，不发布未保存清单，清理临时文件与锁。
- 更新、删除、清空已完成项失败：原数据保留。
- 失败期间另一个实例成功写入，再重试：拒绝旧 revision，保留另一个实例的任务，重新提交成功。
- 文件不可读、损坏文件备份失败：拒绝覆盖；读取不会移动文件。
- 四个进程各新增 15 项：60 项全部保留。
- HTTP 保存/恢复故障返回 503；智能体工具不声称保存成功；存储警告可见。
- 明确选任务才能开始；重复点击不会更换目标或重复提交完成。
- 排序、改名、任务被删除/完成：保持原任务身份，不切换到另一项。
- 离开今天仍计时；超时、暂停、遇阻和刷新可恢复，备注及剩余时间保留。
- 完成保存失败：保留小结和备注，不进入休息；标题编辑失败保留草稿。
- 延迟的旧 revision 响应不能撤销已提交的完成状态。
- 构建产物与源码一致，生成 JavaScript 语法有效，既有动画生命周期和交互测试通过。
