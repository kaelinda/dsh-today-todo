# Changelog

## Unreleased

- **Today add feedback** — successful additions send a composer pulse and give
  the created row a soft entrance, light sweep, and tiny sparks. Independent
  short-lived markers handle repeated titles and rapid adds; failures, polling,
  and conflict snapshots never celebrate. Motion preferences keep a static
  highlight, and a live region announces success. A draft typed while an earlier
  add is pending is preserved. README includes the new interaction GIF.

- **Focus motion** — composer focus sends a soft outward pulse and two light
  trails around the rounded rim; rename/tag/search fields briefly glow on entry.
  Effects follow the theme, stop on blur, and respect both the persisted motion
  switch and live reduced-motion settings. README includes a browser GIF preview.

- **Focus and control states** — a single rounded focus highlight for Today and
  list composers, consistent focus styling for rename/tag/search fields, and
  independent, unclipped keyboard focus on buttons and session choices.
  Disabled controls no longer react to hover; expanded cards retain their accent
  border and pressed buttons keep their text readable.

- **Three.js Today scene** — local, lazily initialized particle orbits surround the
  HTML timer in a dedicated night palette. Focus gathers the particles, breaks
  turn warm, pausing freezes the scene, and task completion sends a soft ripple.
- **Motion lifecycle** — a persisted motion switch, live reduced-motion support,
  30 FPS/DPR caps, container resizing, hidden/offscreen suspension, WebGL fallback,
  and GPU/listener cleanup on exit. Three.js is bundled offline with its license;
  `npm ci` installs the pinned development build tools.

- **Workspace visual refresh** — clearer title and composer, a Today focus entry,
  readable task cards with clickable tags and session links, and quadrant colors
  with action hints. Styles follow the Host theme and the panel's available width.
- **Interaction polish** — visible keyboard focus, larger touch targets, detail
  actions on narrow layouts, loading skeletons, reduced-motion support, and IME
  Enter guards for adding, renaming, and tagging tasks.

- **Matrix view repaired** — the 四象限 / Matrix switch now renders four quadrant
  cells plus an unclassified bucket instead of crashing on a missing
  `renderMatrix` reference. Missing `picker.*` strings were added to both
  dictionaries.
- **Store hardening** — mutations now take an exclusive lock and re-read the
  document before applying, so multiple DSH processes merge instead of
  overwriting each other. Persistence fsyncs the temporary file and the
  directory, and a corrupt document is preserved as
  `todos.json.corrupt-<timestamp>` before the store degrades to empty.
- **Optimistic locking** — the document carries a revision; the panel sends
  `baseRevision` and retries once on `409 todo_revision_conflict` rather than
  clobbering a newer list written by the agent or another tab.
- **Host-owned "today"** — the state response publishes the Host's local day key
  and the panel uses it for counts, filters, zen mode, and the date label.
- **Paged agent list** — `todo_track` `list` now supports
  `scope`/`filterPriority`/`filterQuadrant`/`filterTag`/`filterQuery`/`offset`/
  `limit`, numbers rows by absolute position, and reports `total`, `matched`,
  `offset`, `limit`, and `hasMore`.
- **Tests and build seam** — the client source moved to `src/client/` and
  `client.js` is generated by `scripts/build-client.mjs`; `npm test` covers the
  matrix render, picker strings, Host today, store fsync/recovery/concurrency,
  route status codes, tool paging, and artifact drift.

## 1.0.0 — 2026-11-03

First release.

- **Left sidebar entry** — a checklist icon in the sidebar panel list opens the
  todo panel in the main column.
- **Todo tracking** — add, rename, complete, delete, filter, clear completed; the
  list is stored by the Host in `$DSH_HOME/dsh-todos/todos.json`.
- **Per-item details** — tags (module/category), priority `P0`–`P3`, Eisenhower
  quadrant `Q1`–`Q4`, and a per-day "today" focus date.
- **Zen today mode** — switching the scope to 今天 turns the panel into a quiet
  focus view: enso mark, one add line, today's open items only, collapsed
  completed items, exit with `Esc`.
- **Pomodoro inside zen** — 25 minute focus / 5 minute break with a progress
  ring, breathing and completion animations, pause/resume/end, and `localStorage`
  recovery.
- **Session linking** — link an item to the DSH session that owns the work and
  jump to it in one click, with archived/deleted sessions reported instead of a
  dead navigation.
- **Agent parity** — the `todo_track` tool (list / add / update / remove /
  clearDone, with tags, priority, quadrant and today) calls the same Host store.
- **Compact list redesign** — one toolbar row with scope tabs plus a filter
  popover, one-line rows, details behind a chevron, completed items grouped.
